Dodocommunication 2.0

DESKRIPSI MASALAH:
Lisa sedang mengembangkan Dodocommunication Device menjadi versi 2.0. Alat ini sekarang menggunakan resonansi Vision sebagai antena pengantar sinyal percakapan antar dua orang. 

Berikut adalah topologi dan cara kerja jaringan Dodocommunication 2.0:
1. Jaringan Lokal (Satu Region): Para pengguna Vision di suatu region terhubung secara berantai membentuk lingkaran (Circular Ring). Sinyal dapat menjalar ke dua arah (kiri atau kanan) untuk mencari rute terpendek antar pengguna Vision.
2. Jaringan Global (Antar Region): Jika target berada di region lain, sinyal akan dikirim menuju waypoint pusat yaitu "Tree of Life" di region asal.
3. Transmisi Irminsul: Tree of Life dari seluruh penjuru Teyvat terhubung langsung dengan Irminsul, membentuk lingkaran raksasa (Circular Ring) dua arah. Sinyal akan memutari Irminsul menuju Tree of Life di region target, lalu diteruskan ke Vision target.
4. Setiap kali sinyal berpindah tangan (transmisi/hop), kekuatannya akan melemah. Sinyal memiliki batas timeout selama K detik untuk setiap panggilan.

Karena kamu sangatlah gabut, maka simulasikanlah sistem kerja dari Dodocommunication 2.0 ini!


FORMAT INPUT:
- Baris pertama berisi sebuah bilangan bulat N — jumlah region di Teyvat.
- Diikuti oleh N blok input, di mana setiap blok terdiri dari:
  - Sebuah string yang merupakan nama Region (sekaligus penanda Tree of Life).
  - Deretan string nama-nama pengguna Vision di region tersebut, dipisahkan oleh spasi. Input daftar karakter di sebuah region selalu diakhiri dengan string "end".
- Setelah semua blok region selesai, terdapat sebuah bilangan bulat Q — jumlah pengujian panggilan.
- Q baris berikutnya masing-masing berisi tiga buah variabel yang dipisahkan spasi: A (string), B (string), dan K (integer). A adalah nama pengirim, B adalah nama penerima, dan K adalah Waktu timeout untuk panggilan tersebut.

FORMAT OUTPUT:
Untuk setiap uji coba komunikasi:
- Jika rute terpendek (jumlah transmisi) <= K, cetak: "Connected on [jumlah transmisi] second"
- Jika rute terpendek (jumlah transmisi) > K, atau salah satu karakter tidak ditemukan di database, cetak: "Signal lost"

BATASAN (CONSTRAINTS):
- 1 <= N <= 10
- 1 <= Q <= 1.000
- 1 <= K <= 10.000
- Total pengguna Vision secara keseluruhan tidak akan melebihi 100.000 karakter.
- Semua nama region dan karakter hanya terdiri dari huruf alfabet dan dijamin unik.

PENJELASAN CONTOH:
- Query 1 (Amber ke Zhongli, Maks 3): 
  Rute terpendek: Amber -> Tree Mondstadt -> Tree Liyue -> Xiangling -> Zhongli. 
  Total transmisi = 4 hop. Karena 4 > 3, komunikasi gagal (Signal lost).
  
- Query 2 (Kaeya ke Barbara, Maks 5): 
  Satu region, sehingga sinyal mem-bypass Tree of Life. Rute melingkar terpendeknya (mundur): Kaeya -> Diluc -> Venti -> Barbara. 
  Total transmisi = 3 hop. Karena 3 <= 5, komunikasi sukses (Connected on 3 second).
  
- Query 3 (Nahida ke Ganyu, Maks 10): 
  Beda region. Rute terpendek memutar ke belakang saat di Liyue: Nahida -> Tree Sumeru -> Tree Liyue -> Ganyu. 
  Total transmisi = 4 hop. Karena 4 <= 10, komunikasi sukses (Connected on 4 second).
