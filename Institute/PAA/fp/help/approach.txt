[PLANNER] Model + algorithmic plan + correctness/complexity (no code) → Formalize as a constrained 2‑factor on a planar graph, reduce to perfect matching, and decode mirrors

**Mathematical model**
- Treat each *cell side* as a node (“side‑node”). Two side‑nodes are adjacent if they are opposite sides of the same shared cell edge (the laser moves straight across that shared edge without choice).
- Each cell contributes a *local pairing* of its four side‑nodes. There are exactly two allowed pairings (the mirrors):  
  - “/”: $(N \leftrightarrow W)$ and $(S \leftrightarrow E)$  
  - “\”: $(N \leftrightarrow E)$ and $(S \leftrightarrow W)$
- A mirror configuration is therefore a choice of one of those two pairings at every cell.  
  If you take the union of:
  1) all fixed adjacency links between side‑nodes of neighboring cells, and  
  2) the chosen pairings inside each cell,  
  you get a graph of degree 2 at every *internal* side‑node and degree 1 at each *boundary* side‑node.  
  This graph decomposes into disjoint cycles and open paths; each open path connects exactly two boundary side‑nodes (the lasers).  
  The required blueprint is exactly a requirement on which boundary side‑nodes are connected.

**Necessary quick checks (fast rejections)**
- **Planarity (non‑crossing) is necessary**: any realizable pairing is noncrossing with respect to the cyclic order of boundary ports.
- **Parity invariant (necessary)**: let each boundary port be adjacent to cell $(r,c)$, and let $o=0$ for vertical ports (top/bottom) and $o=1$ for horizontal ports (left/right). Define $v=o\oplus (r+c \bmod 2)$. Any connected pair must have opposite $v$ (i.e., $v_a \oplus v_b = 1$).  
  This follows from alternating turns and the checkerboard parity of the grid.

These are **necessary but not sufficient**, so they’re only early pruning.

## Core algorithmic approach (polynomial, constructive)

### Step 1 — Build the “side‑node” graph $G$
- One node per side of every cell.  
- Add **fixed adjacency edges** between opposite sides of neighboring cells (laser travel between cells).  
- Add a degree‑1 “external edge” from each boundary side‑node to a dummy terminal node representing that boundary port.

### Step 2 — Encode the required boundary pairing
For each label pair $(p,q)$, add an **auxiliary edge** connecting the two terminal nodes of $p$ and $q$.  
This turns each desired open path into a cycle once the interior is solved.

**Reasoning:** In any valid solution, each boundary side‑node has degree 1 in the interior graph. Adding the pair edge makes the terminal nodes degree 2, so any 2‑factor (degree‑2 subgraph) must include those pair edges and therefore connects exactly those boundary endpoints.

### Step 3 — Reduce to a constrained 2‑factor
We must select, at each cell, *one* of the two allowed pairings.  
This yields a subgraph where:
- every side‑node has degree 2 (one fixed adjacency edge + one chosen mirror edge),  
- every terminal node has degree 2 (boundary port edge + pair edge).  

So we need a **2‑factor** that respects the cell‑pairing constraints.

### Step 4 — Reduce 2‑factor to perfect matching
Use a standard reduction from degree‑2 subgraph selection to perfect matching (Tutte’s reduction):
- Replace each side‑node by a small gadget that enforces “exactly one incident mirror edge is chosen.”
- For each cell, only allow the two pairings that correspond to “/” or “\” (this is a 4‑node gadget with exactly two perfect matchings).
- This yields a planar (often bipartite) graph $H$ where **perfect matchings $\leftrightarrow$ valid mirror configurations**.

### Step 5 — Solve matching and decode mirrors
- Find a perfect matching in $H$.  
- If none exists, answer is $-1$.  
- Otherwise, the chosen edges inside each cell tell you whether the cell is “/” or “\”.

## Correctness sketch
- **(Soundness)** Any mirror configuration gives a degree‑2 subgraph of $G$ that includes all auxiliary pair edges, therefore each label pair becomes one cycle. Removing auxiliary edges yields exactly the required boundary connections.
- **(Completeness)** Any 2‑factor in $G$ that uses the auxiliary pair edges corresponds to a mirror choice at each cell (because the only allowed degree‑2 pairings at a cell are “/” or “\”). Thus every valid pairing is representable.
- **(Matching reduction)** The gadget construction is a bijection between valid 2‑factors of $G$ and perfect matchings of $H$.

---

## Complexity
Let $N=O(XY)$ be the number of cells.  
- Side‑nodes: $O(XY)$, edges: $O(XY)$.  
- Matching graph $H$: $O(XY)$ vertices/edges (constant‑size gadgets per cell/side‑node).  
- Perfect matching:
  - General graph: $O(N^3)$ (Edmonds).  
  - Planar/bipartite matching: $O(N^{1.5})$–$O(N^{2})$ using planar or Hopcroft–Karp variants.

So overall **polynomial time**, comfortably within constraints for $X,Y \le 100$.

- A mirror layout is valid iff the union of chosen mirror edges and fixed adjacency edges makes every side‑node degree 2; the resulting paths connect boundary lasers exactly by the given labels.

→ **Necessary fast checks (your friend's hint fits here)**  
Scan boundary lasers in clockwise order using a **hashmap** (label -> first index) and a **stack** to ensure non‑crossing nesting.  
- **Non‑crossing condition**: when a label appears the second time, it must match the stack top. Otherwise, crossings are forced → impossible.  
- **Parity invariant**: for a boundary port adjacent to cell $(r,c)$, let  
  $$o=\begin{cases}0,&\text{top/bottom}\\1,&\text{left/right}\end{cases}$$  
  $$v=(r+c)\bmod 2 \oplus o$$  
  Any connected pair must have **opposite** $v$ (proof: each cell turn flips orientation, moving to the next cell flips $(r+c)$, so $v$ is invariant for the “before‑mirror” state, which means boundary ports must differ).  
If either check fails, return $-1$ immediately.

→ **Main construction: reduce to a 2‑factor, then perfect matching**  
1. Build graph $G$ with vertices = all side‑nodes plus terminal nodes for each boundary laser.  
2. Add fixed edges: adjacency between neighboring sides, and each terminal to its boundary side‑node.  
3. Add **pair edges** between terminals that share the same label (from the scan).  
4. Inside each cell, allow only the two mirror pairings above.  
We must choose mirror edges so that **every vertex has degree 2**, and all fixed edges are included. This is a **constrained 2‑factor** problem.

→ **2‑factor → perfect matching (standard reduction)**  
Use Tutte’s reduction: replace each vertex $v$ by a cycle gadget that represents its incident edges; selecting a perfect matching in the derived graph corresponds to selecting exactly two incident edges at each original vertex (thus a 2‑factor).  
- Fixed edges (adjacency + pair edges) are forced in the 2‑factor, so they are pre‑selected in the gadget.  
- Cell gadgets only permit the two legal mirror pairings.  
If the derived graph has a perfect matching, decode each cell’s pairing to "/" or "\". Otherwise output $-1$.
